A mobile-first responsive portfolio showcasing my professional experiences in consulting, modeling, public speaking, and technology.

Features:
- CSS Grid for the overall page layout
- Flexbox for navigation, content, and portfolio cards
- Mobile-first responsive design
- Responsive sidebar navigation
- Portfolio cards with images and descriptions
- Contact form

Responsive Layout

The page uses a one-column layout on mobile screens and changes to a sidebar layout on larger screens using a media query.
